# Domain Docs

Read [the root glossary](../../GLOSSARY.md) before using repository terminology. Before changing an area, read its relevant [decisions](../adr/README.md).

Use glossary terms in issue titles, specs, and implementation notes. When a domain term is settled during a discussion, record it in the root glossary. Record an architectural decision in `docs/adr/` when it meets the repository's criteria for an ADR.

Call out any conflict with an accepted ADR so the maintainer can decide whether to revisit it.
