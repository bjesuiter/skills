# Jamon Holmgren gists

[Overnight mode](overnight-mode/SKILL.md) adapts Jamon Holmgren's [overnight-work prompt](https://gist.github.com/jamonholmgren/caf41394d6643be4ceecbaa7c22f90b8). The [vendor manifest](vendor.json5) tracks the gist's only file and pins the source revision.

The gist publishes a setup prompt without a license file or license notice. This distribution implements the workflow in its own skill and shared Claude Code and Codex hook. Review future changes to `Overnight-mode.md` and port applicable behavior into the local skill.
