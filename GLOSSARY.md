# JB Skills

This repository contains agent skills JB maintains and adapts for his workflows.

## Language

**Skill** is a named set of instructions an agent can load for a specific task.

**Vendored skill** is a skill from another source whose copy JB maintains and can adapt in this repository.

**Draft skill** is a skill under development that has yet to be included in the main catalog.

**Main catalog** is the list of skills recommended for use in the repository README.

**Preferred Registry** is JB's list of agent resources and their installation settings.

**Retired skill** is a skill removed from the active catalog whose reason for retirement and replacement, if available, are recorded in the retirement history.
